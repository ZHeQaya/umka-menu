Меню сообщества

Бесплатная замена платному виджету «Навигация». Приложение ставит в сообщество виджет-список (виджет сообщества), который появляется в верхней части страницы — на сайте и в мобильных приложениях.

Предпросмотр (так будет выглядеть блок)

Ссылки пунктов — проверьте, что открывается поиск по хештегу

Откройте пару ссылок в ВК. Если выдача пустая — значит публикаций с таким хештегом ещё нет.

1. Добавить приложение в сообщество

Нажмите кнопку и выберите сообщество vk.ru/ymka32020.

2. Установить / обновить виджет

Устанавливать нужно от имени администратора сообщества.

Приложение открыто вне ВКонтакте

Установка виджета работает только внутри ВК. Откройте приложение по ссылке https://vk.com/app<ID> (в приложении ВК — отправьте ссылку себе в «Избранное»).
