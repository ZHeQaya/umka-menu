# Меню сообщества «Умка» — бесплатный виджет вместо платного конструктора

Готовое мини-приложение, которое ставит в сообщество **виджет сообщества** — тот самый блок
с пунктами меню в верхней части страницы (как на скриншоте). Механизм есть у платформы
VK Mini Apps и он бесплатный: платный конструктор виджетов просто продаёт удобную обёртку над ним.

Пункты меню ведут на поиск по хештегу внутри вашего сообщества.
Перед каждым пунктом стоит иконка белого медвежонка 🐻❄️ (меняется одной строкой в `app.js` — `CONFIG.icon`).

Ссылка собирается автоматически, например:
`https://vk.com/ymka32020?q=%23УмкаВДеле` — открывает сообщество с поиском по хештегу.

> Если какой-то хештег захочется изменить — правьте только `app.js`, таблица выше просто справка.
> Хештеги должны реально стоять в текстах ваших публикаций, иначе выдача будет пустой.
> Перед запуском стоит опубликовать по одному посту с каждым хештегом и проверить ссылки.

**Проверка перед установкой.** На странице приложения ссылки из блока «Ссылки пунктов» кликабельны:
нажмите пару штук (в браузере, где вы залогинены в ВК) и посмотрите, что открывается.

В приложении есть переключатель **«Куда ведут пункты меню»**:

* **Поиск по хештегу внутри сообщества** (рекомендуется) — `vk.com/ymka32020?q=%23Хештег`.
* **Общий поиск ВК по хештегу** (запасной вариант) — `vk.com/feed?section=search&q=%23Хештег`.
  Работает всегда; хештеги уникальные, поэтому выдача — практически только ваши записи.

Если первый вариант откроет просто стену сообщества без фильтра — выберите второй и нажмите
«Установить виджет» ещё раз. Менять код руками не нужно.

## 3. Хостинг через GitHub Pages (бесплатно, без программирования)

1. Зайдите на [github.com](https://github.com) → **New repository**.
   Имя, например `umka-menu`, тип — **Public** → **Create repository**.
2. На странице репозитория: **Add file → Upload files**, перетащите `index.html` и `app.js`,
   нажмите **Commit changes**.
3. **Settings → Pages**: в блоке *Build and deployment* выберите
   **Source: Deploy from a branch**, **Branch: main**, папка **/ (root)** → **Save**.
4. Через 1–2 минуты страница обновится, появится адрес вида
   `https://<ваш-логин>.github.io/umka-menu/`.
5. Откройте этот адрес в браузере — увидите страницу с предпросмотром меню.
   Кнопки установки на этом этапе будут писать «приложение открыто вне ВКонтакте» — это нормально.

---

## 4. Регистрация мини-приложения (dev.vk.com, бесплатно)

1. Откройте [dev.vk.com](https://dev.vk.com) → **Приложения** → **Создать приложение**.
2. Тип — **Мини-приложение**, категория — любая (например, «Образование»),
   название — например «Меню Умки». Нажмите **Создать** и подтвердите действие с телефона.
3. Запишите **ID приложения** (число) — оно понадобится.
4. **Настройки → Информация** → включите **«Запуск приложения из сообщества»**.
   Без этого кнопка «Добавить в сообщество» не сработает.
5. **Настройки → Размещение** → в блоках веб-версии и мобильной версии укажите URL из GitHub Pages
   (шаг 4 предыдущего раздела). Сохраните. Адрес обязательно HTTPS — GitHub Pages его даёт.

## 5. Установка виджета в сообщество

1. Откройте своё приложение: `https://vk.com/app<ID>` (на телефоне удобно отправить эту ссылку
   себе в «Избранное» и открыть оттуда).
2. Нажмите **«Добавить в сообщество»** → выберите сообщество `Умка` (`vk.ru/ymka32020`).
3. В поле появится ID сообщества. Выберите формат ссылок и нажмите **«Установить виджет»** →
   откроется предпросмотр → подтвердите установку.
4. Блок появится в верхней части страницы сообщества — и в полной версии сайта, и в мобильных приложениях.

> Если VK откажется устанавливать виджет у неопубликованного приложения — отправьте приложение
> на модерацию в панели управления (раздел «Модерация»), это бесплатно.
>
> Widget можно установить, только будучи администратором сообщества.

## 6. Как менять меню потом

1. Поправьте в `app.js`: `CONFIG.icon` — иконка, `CONFIG.items` — подписи и хештеги.
2. Загрузите обновлённый файл в репозиторий (Add file → Upload files → Commit).
3. Снова откройте приложение и нажмите **«Установить виджет»** — новый код перезапишет виджет.
   Содержимое виджета фиксируется в момент установки, поэтому переустановка обязательна.

## 7. Как заливать обновления на GitHub

### Способ 1 — заменить файл через сайт (для любых правок)

1. Откройте [github.com](https://github.com), войдите и зайдите в свой репозиторий (например `umka-menu`).
2. Нажмите **Add file → Upload files**.
3. Перетащите новые `app.js` и `index.html` из папки `vk-menu-widget`.
   Имена должны совпадать с теми, что уже в репозитории — тогда GitHub поймёт, что это замена,
   а не новые файлы.
4. Внизу в поле **Commit changes** напишите коротко, что изменили (например «иконка медвежонка»),
   и нажмите **Commit changes**.
5. Подождите 1–2 минуты — GitHub Pages пересобирает сайт автоматически.
   Затем откройте `https://<ваш-логин>.github.io/umka-menu/` и обновите страницу через **Ctrl+F5**.

### Способ 2 — поправить одну строку прямо в GitHub (быстрее всего)

1. Откройте файл `app.js` в репозитории.
2. Нажмите значок **карандаша** (*Edit this file*).
3. Измените нужную строку, например `icon: '🐻❄️',` → `icon: '🐻',`.
4. Нажмите **Commit changes** и подтвердите.
5. Через 1–2 минуты обновите страницу приложения через **Ctrl+F5**.

### Обязательный шаг после обновления файлов

Откройте своё приложение в ВК (`https://vk.com/app<ID>`) и снова нажмите **«Установить виджет»**.
Содержимое блока в сообществе фиксируется в момент установки — без этого на странице сообщества
останется старое меню.

> Если через пару минут изменения не видны — откройте страницу приложения в режиме инкогнито
> или проверьте, что коммит действительно появился в репозитории (вкладка **Commits**).

## Ограничения платформы

* В виджет можно вставлять **только внутренние ссылки ВК**: `vk.com`, `vk.ru`, `vk.me`.
  Внешние сайты и `away.php` не принимаются.
* Тип `table` (используется сейчас) — до 6 колонок × 11 строк. Сейчас: 2 колонки × 5 строк = 10 пунктов.
  Колонки меняются в `app.js` (`columns: 2` или `3`).
* Тип `list` / `compact_list` — максимум **6** пунктов, для 10 не подходит.
* Подпись пункта — до 100 символов, заголовок — до 100.
* Иконка 🐻❄️ — составной эмодзи (медведь + снежинка). На новых устройствах он показывается
  белым медвежонком, на старых Android/Windows может отрисоваться как «медведь + снежинка»
  или квадратиком. Тогда в `app.js` поставьте `icon: '🐻'` или `icon: '❄️'` — поменяется
  сразу у всех пунктов, после чего залейте файл и переустановите виджет.

## Альтернативы без мини-приложения

1. Закреплённый пост или статья со списком хештегов — бесплатно, но это не отдельный блок.
2. Встроенные разделы сообщества («Обсуждения», «Ссылки») — бесплатно, но выглядят иначе.
3. Платный конструктор виджетов — если совсем не хочется возиться с GitHub.
