# Меню сообщества «Умка» — виджет на странице ВК

Мини-приложение, которое ставит на страницу сообщества блок с пунктами меню (виджет сообщества)
и позволяет править этот список **прямо во ВКонтакте, в том числе с телефона**.

* Приложение: `app54809979` → https://vk.com/app54809979
* Сообщество: `club212278594` → https://vk.com/ymka32020
* Страница приложения (хостинг): https://zheqaya.github.io/umka-menu/
* Репозиторий: https://github.com/ZHeQaya/umka-menu

---

## Что изменилось в этой версии (важно)

1. **VK Bridge вшит локально** (`vk-bridge.min.js`). Раньше он грузился с внешнего CDN —
   именно из-за этого приложение могло «висеть» при запуске с телефона. Теперь внешних
   зависимостей нет вообще.
2. **Список пунктов редактируется внутри ВК.** Одна строка — один пункт: `Название | хештег`.
3. **Правки сохраняются в VK Storage** — хранилище ВК привязано к аккаунту, а не к телефону,
   поэтому со второго устройства список будет тот же.
4. **Кнопка «Обновить виджет в сообществе»** переставляет блок на странице сообщества
   без GitHub.
5. ID приложения (54809979) и сообщества (212278594) уже прописаны в `app.js`.
6. **В пунктах меню теперь логотип Умки**, а не эмодзи: см. раздел ниже.

## Логотип Умки в пунктах меню

В блоке виджета картинку можно показать только через поле `icon_id`, а самый простой бесплатный
источник — **иконка самого приложения**: `icon_id: "app54809979"`. То есть в пунктах появится ровно
тот логотип, который вы загрузите в **Настройки → Оформление → Универсальная иконка** (`icon-576.png`).

**Порядок важен:** сначала загрузите иконку 576×576 в настройках приложения, потом ставьте виджет —
иначе ВК нечего будет показывать.

В приложении есть два переключателя:

* **Иконка пунктов** — «Логотип Умки» или «Эмодзи 🐻».
* **Вид блока** — «Плитки» (логотип на каждом пункте, 3–10 штук), «Таблица» (логотип только
  в левой колонке, 24×24) или «Список» (до 6 пунктов, логотип у каждого, 50×50).

Ограничения ВК, из-за которых так сделано:

* в таблице картинка допустима **только в первой ячейке строки** — при 2–3 колонках логотип будет
  лишь у левой колонки; чтобы он был у всех пунктов, выбирайте «Плитки» или список в 1 колонку;
* в списке картинка должна быть **либо у всех пунктов, либо ни у кого**;
* плиток может быть **от 3 до 10**.

По умолчанию включены «Плитки» + логотип — это ближе всего к исходному меню со скриншота.
Если плитки не понравятся, переключите вид блока и нажмите «Обновить виджет в сообществе».

2. Перетащите **все четыре файла** (имена должны совпадать с существующими — тогда это замена).
3. **Commit changes**, подождите 1–2 минуты.
4. Проверьте: https://zheqaya.github.io/umka-menu/ (обновить через **Ctrl+F5**).

## Настройки приложения в dev.vk.com — проверьте по списку

Это главное место, из-за которого приложение не запускается и виджет не ставится.
Панель: https://dev.vk.com/ru/admin/apps-list → приложение `app54809979`.

**Настройки → Информация**

* **Тип приложения.** Если стоит «Мини-приложение», а виджет не устанавливается —
  создайте приложение типа **«Плагин для сообществ»** и укажите ему тот же URL.
  Виджеты сообществ — это функция плагинов.
* **Запуск приложения из сообщества** — включено.
* **Официальное сообщество** — «Умка» (`club212278594`).
* **Company name** (раздел «Запуск на iOS») — любое название (например, `Umka`).

**Настройки → Размещение**

* URL приложения укажите одинаковым для всех платформ (Web, Mobile Web, iOS, Android):
  `https://zheqaya.github.io/umka-menu/`
* **Состояние для пользователей** — **Включено**. Без этого приложение видно только вам,
  и запуск может не работать.

## Как установить виджет

1. Добавьте приложение в сообщество: в самом приложении нажмите
   **«Добавить приложение в сообщество»**, либо в сообществе
   **Управление → Приложения → Мои приложения → Добавить**.
2. Откройте приложение **в контексте сообщества** — по ссылке
   https://vk.com/app54809979_-212278594 (в приложении есть кнопка
   «Открыть в контексте сообщества»).
3. Нажмите **«Обновить виджет в сообществе»** → откроется предпросмотр → подтвердите.
4. Блок появится в верхней части страницы сообщества.

> Карточка приложения в сообществе («кто сделал», «отправить») — это не виджет.
> Пока виджет не установлен, блока с пунктами меню на странице не будет.

## Как управлять меню (в том числе с телефона)

1. Откройте приложение внутри ВК (ссылка выше или карточка приложения в сообществе).
2. В блоке **«Пункты меню»** правьте строки в формате:

   ```
   Итоги недели | #УмкаИтогиНедели
   Умка в деле | #УмкаВДеле
   Полезная ссылка | https://vk.com/wall-212278594_123
   ```

   Второе поле — хештег (можно без `#`) либо полная ссылка ВК.
3. **«Сохранить»** — список уходит в хранилище ВК (доступен с любого устройства).
4. **«Обновить виджет в сообществе»** — блок на странице сообщества обновляется.

### Какие ссылки получаются из хештегов

| Режим в приложении | Адрес |
|---|---|
| Поиск по записям сообщества (по умолчанию) | `https://vk.com/wall-212278594?q=%23УмкаВДеле` |
| Общий поиск ВК по хештегу | `https://vk.com/feed?section=search&q=%23УмкаВДеле` |

Первый вариант — это штатный «поиск по записям» стены сообщества. Важно: адрес вида
`vk.com/ymka32020?q=…` (короткое имя вместо `wall-<ID>`) фильтр **не включает** — раньше
использовался он, поэтому выдача показывала все посты подряд. Если и `wall-<ID>` в вашем
клиенте не отфильтрует, переключите режим на «Общий поиск ВК по хештегу» и снова нажмите
«Обновить виджет в сообществе».

Заголовок блока меняется в `app.js` (`CONFIG.title`).

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| На странице сообщества карточка приложения вместо меню | Виджет ещё не установлен. Откройте приложение в контексте сообщества и нажмите «Обновить виджет в сообществе». |
| Приложение висит/белый экран на телефоне | Раньше подводил внешний CDN — теперь `vk-bridge.min.js` локальный. Убедитесь, что он залит в репозиторий и открывается по адресу `https://zheqaya.github.io/umka-menu/vk-bridge.min.js`. |
| «Ошибка установки виджета» | Вы не администратор сообщества, либо приложение не добавлено в сообщество, либо тип приложения — «Мини-приложение» (нужен «Плагин для сообществ»). |
| Приложение открывается, но без контекста | Открывайте по ссылке `vk.com/app54809979_-212278594` или из сообщества. |
| Изменения не появились в сообществе | Нажмите «Сохранить», затем «Обновить виджет в сообществе» и подтвердите. |
| Пункт открывает сообщество, но без фильтра по хештегу | Переключите «Куда ведут ссылки из хештегов» на «Общий поиск ВК по хештегу» и нажмите «Обновить виджет в сообществе». |
| Предупреждение «непроверенное приложение» | Нормально. На iOS без модерации плагин открывается в мобильной версии сайта ВК. |
| Ничего не помогло | Нажмите «Данные запуска» и «Скопировать журнал» — там видно, что именно ответил ВК. |

## Ограничения платформы

* Только внутренние ссылки ВК: `vk.com`, `vk.ru`, `vk.me`.
* Тип `table` — до 6 колонок × 11 строк; `list`/`compact_list` — максимум 6 пунктов.
* Подпись пункта и заголовок — до 100 символов.
* VK Storage: до 4096 символов на значение (наш конфиг ~650).
* Хештеги должны стоять в текстах публикаций, иначе выдача поиска будет пустой.
